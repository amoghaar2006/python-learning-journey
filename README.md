# Python Learning Journey 🐍

This repository documents my independent Python practice while revisiting fundamental concepts through Microsoft's official **Python for Beginners** video series.

Although I had prior experience with Python, I wanted to strengthen my fundamentals through hands-on practice and improve my understanding of Python programming.

## 📚 Topics Covered

- **Python Basics:** Print statements, comments and numeric data types
- **Strings:** String concepts and string formatting
- **Conditional Statements:** Conditional logic and complex conditions
- **Data Structures:** Lists and working with collections
- **Loops:** Iteration and repetitive tasks
- **Functions:** Defining and using reusable functions
- **Date and Time:** Working with dates and time formatting
- **JSON:** Understanding and working with JSON data

## 🎯 Learning Objectives

- Strengthen my understanding of Python fundamentals.
- Practise programming concepts through Jupyter Notebooks.
- Improve problem-solving and logical thinking.
- Build a foundation for further learning in data analytics, data science and automation.
